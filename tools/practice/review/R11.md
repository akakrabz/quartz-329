## Findings and changes

**M1 (major, requested): 11.8 (a)–(b) duplicated problem 8.10 and Summer 2017 HE2 #2a; source line said "classic".**
The cos 3x relaxation with E from Gauss repeated 8.10 (18ε₀ cos 3x) and S17 HE2 #2a (cos 3z). The Sources paragraph
also said no old exam was re-parameterized, contradicting the S17 model and SPEC §2. Changes:
- (a) now uses ρ(x,0) = ρ₀ sin βx in a uniform conducting medium (σ, ε) and asks on which planes E_x = 0. The new twist
  is the integration constant: E_x = −(ρ₀/βε) cos βx e^{−t/τ_r} + C, and C = 0 because ρ is symmetric about the
  crest and trough planes. So E_x vanishes where \|ρ\| is largest and peaks where ρ = 0. This comes with a Watch-out, and
  the hint was extended. The script also shows that a sheet sum over a window centred on a node gives the wrong E(0).
- (b) uses lightly doped n-Si: ε = 11.7ε₀, N = 1.0e20 m⁻³, m* = 0.26 m_e, τ = 1.8e-13 s, with ρ₀ = 46.8ε₀ C/m³ and β = 2 rad/m.
  β = 2 avoids the 3 of S17 and 8.10 and the sin 4z of Summer 2020 HE2 #1b. Results: σ = 1.95 S/m, τ_r = 5.31e-11 s
  (53 ps), amplitude 2 V/m. At the node x = 0: E = −2 x̂ V/m, J = −3.90 x̂ A/m², v = +0.244 x̂ m/s. The current
  runs crest (π/4 = 0.785 m) → trough (−π/4 m) and the electrons drift the other way; ρ₀/e = 2.6e9 m⁻³ ≪ N.
- (c) adds the silicon contrast (τ_r = 295τ, so J = σE holds there). (d) is unchanged apart from m2 and one added
  line in "When is ε/σ right?": silicon 4τ = 7.2e-13 s, slow-root time constant 5.29e-11 s, 0.34% below τ_r.
  The Check and Answer lines were updated.
